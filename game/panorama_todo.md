Красота в Panorama держится на трёх вещах: единый визуальный стиль, движение и использование родных элементов Dota. Panorama умеет больше, чем обычно используют в кастомках, — это не просто CSS для простых панелей.

1. Определите визуальную идентичность

Сначала стоит решить, как мод должен выглядеть в целом, и только потом рисовать панели. Хорошо работает такая схема: основа в стиле Dota (тёмные полупрозрачные панели, тонкие светлые рамки, золотые акценты), чтобы HUD не выглядел чужеродным, плюс один фирменный цвет «хаоса», например фиолетово-малиновый. Его используют только для хаос-элементов: таймера ротации, баннеров событий, казино. Тогда игрок с одного взгляда отличает механики мода от родного интерфейса.

Зафиксируйте палитру и размеры в одном общем CSS-файле: 4–5 цветов, 3 размера шрифта, единый шаг отступов (например, кратный 4px). Для шрифтов лучше использовать родные шрифты Dota: Radiance для текста и Reaver для заголовков. Так HUD выглядит частью игры.

2. Движение — главный рычаг

Статичная панель, которая просто появляется, выглядит дёшево. Та же панель с короткой анимацией выглядит дорого. Panorama поддерживает transition, @keyframes и 3D-трансформации.

Обычный приём: стиль задаёт два состояния, а JS переключает класс через SetHasClass.

css
.ChaosBanner {
background-color: gradient( linear, 0% 0%, 100% 0%, from( #5b1a8a ), to( #b3175a ) );
box-shadow: 0px 0px 24px #b3175a80;
opacity: 0;
transform: translateY( -40px );
transition-property: opacity, transform;
transition-duration: 0.35s;
transition-timing-function: ease-out;
}
.ChaosBanner.Visible {
opacity: 1;
transform: translateY( 0px );
}

Идеи для ваших механик:

Смена способности. Карточка переворачивается по оси Y (rotateY): старая иконка уходит, новая появляется с короткой вспышкой. Это намного заметнее всплывающей надписи.
Выбор из трёх. Карточки выезжают с небольшой задержкой друг за другом. При наведении карточка слегка увеличивается и подсвечивается, выбранная остаётся, остальные гаснут.
Предупреждение о хаос-раунде. Баннер с пульсацией плюс тонкая цветная виньетка по краям экрана. Виньетку делают полупрозрачным градиентом на всю ширину с hittest="false", чтобы она не перехватывала клики.
Казино. Барабаны крутятся быстро и останавливаются по очереди с небольшим «отскоком». Последний барабан можно останавливать чуть дольше, это создаёт напряжение. Джекпот стоит сопроводить частицами.

Анимации должны быть короткими: 0,2–0,4 секунды для обычных переходов. В бою долгие анимации раздражают.

3. Используйте родные элементы Dota

У Panorama есть готовые панели, которые сразу делают интерфейс профессиональным.

DOTAAbilityImage показывает иконку способности по имени, без ручного добавления картинок.
Родные тултипы способностей вызываются через $.DispatchEvent("DOTAShowAbilityTooltip", panel, abilityName). Игрок видит описание в привычном виде, и вам не нужно дублировать тексты.
DOTAParticleScenePanel встраивает частицы прямо в интерфейс: искры при выигрыше, свечение карточки редкой способности.
DOTAScenePanel показывает 3D-модели, например вращающийся автомат или курьера в итогах матча. 4. Круговой таймер, как у кулдаунов

Таймер ротации будет выглядеть родным, если сделать его кольцом, как перезарядку способностей в Dota. Для этого используется радиальная обрезка:

js
var progress = remaining / interval; // от 1 до 0
ring.style.clip = "radial( 50% 50%, 0deg, " + (progress \* 360) + "deg )";

Когда до смены остаётся 10 секунд, кольцо можно перекрашивать в цвет хаоса и включать пульсацию.

5. Производительность

Красивый HUD не должен тормозить игру. Не обновляйте панели каждый кадр через $.Schedule(0, ...): для таймеров достаточно 10 обновлений в секунду. Полосу обратного отсчёта можно вообще не обновлять из JS: один раз выставить transition-duration, равный оставшемуся времени, и задать конечную ширину. Анимацию выполнит движок. Размытие (blur) и большое число частиц дороги, их стоит использовать точечно.

6. Разные экраны

Panorama масштабирует интерфейс по высоте экрана, поэтому удобно рисовать под 1920×1080 и задавать позиции через выравнивание (horizontal-align, vertical-align) и проценты, а не через абсолютные координаты. Обязательно проверьте 21:9 и 4:3: на широких экранах панели, привязанные к краю, уезжают далеко от центра, а на 4:3 могут перекрыть родной HUD. Ещё одно правило: центр экрана — для игры. Постоянные элементы держите у краёв, а в центре показывайте только кратковременные события.

7. Рабочий процесс
   Макет до кода. Набросайте экран в Figma или похожем редакторе поверх скриншота Dota. Так проще найти стиль, чем перебирать CSS в игре.
   Горячая перезагрузка. В Workshop Tools изменения CSS и разметки применяются при сохранении файла, без перезапуска матча. Для отладки есть встроенный Panorama Debugger, где видно дерево панелей и применённые стили.
   Референсы. Хорошие образцы — интерфейсы Battle Pass, событийных режимов Valve (Aghanim’s Labyrinth, Overthrow) и популярных кастомок. Смотрите, как там сделаны появление панелей, подсветка и звук.
   Звук вместе с анимацией. Каждая заметная анимация должна сопровождаться коротким UI-звуком через Game.EmitSound. Звук делает интерфейс ощутимо «дороже».
